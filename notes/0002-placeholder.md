This is a placeholder note so the site has more than one entry while
you decide what to actually write about. Delete it (or set
`status: draft`) once you have real content.

The convention: create a new file in `notes/`, give it a leading
numeric prefix for sort order if you care, fill in the frontmatter,
write Markdown below the second `---`, and run `python3 build.py`.

Slug = filename without `.md`. So `notes/0002-placeholder.md` becomes
`/notes/0002-placeholder.md` and `/notes/0002-placeholder.html`.
